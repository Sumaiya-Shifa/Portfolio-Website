# Sumaiya Fahmida Shifa — Portfolio

A cinematic, streaming-inspired portfolio for Sumaiya Fahmida Shifa. Uses the existing biography, education, skills, projects, portrait, posters, and contact email.

Open index.html directly, or run `python -m http.server 5173` and visit http://localhost:5173.

Content lives in index.html; styles in style.css; filtering, project details, mobile navigation and email draft composition in main.js. There is no build step.

The original files are preserved in backup-original/. The visual direction is inspired by https://github.com/Sushmitadasari/Portfolio_series; this implementation uses original HTML/CSS/JavaScript rather than copying that repository.

The three newly added projects link to their supplied GitHub repositories. Older projects without source URLs remain marked as coming soon. Research PDFs and the SQT report are linked from sources/. No certifications are claimed. The contact form opens an email draft; it does not send mail itself. Fonts and icons load from Google Fonts and cdnjs.

The supplied biography says graduate, while the education dates say 2023–Present. Both are preserved pending confirmation.
