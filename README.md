# Sumaiya Fahmida Shifa | Portfolio Website

A modern, responsive personal portfolio website built with HTML, CSS, and JavaScript. This project showcases my academic journey, technical skills, selected projects, poster presentations, and contact information in a clean and professional layout.

## Live Demo

- GitHub Pages: https://sumaiya-shifa.github.io/Sumaiya-Shifa/
- Repository: https://github.com/Sumaiya-Shifa/Portfolio-Website

## About

This portfolio website is designed to present my profile as a Computer Science and Engineering student with a strong interest in full-stack development, software quality assurance, and problem solving. It includes:

- Hero/about section
- Education timeline
- Technical skills overview
- Project showcase
- Poster and academic work gallery
- Contact section with email and social links

## Features

- Responsive design for desktop, tablet, and mobile devices
- Modern glassmorphism-inspired UI
- Smooth navigation and section-based layout
- Project filtering by category
- Academic poster showcase with downloadable PDFs
- Contact form that opens an email draft
- Dark/light themed presentation
- Accessible and user-friendly interface

## Getting Started

### Option 1: Open directly in the browser

1. Download or clone this repository.
2. Open `index.html` in your browser.

### Option 2: Run with a local server

You can also use a local development server such as Live Server in VS Code.

```bash
# Clone the repository
git clone https://github.com/Sumaiya-Shifa/Portfolio-Website.git

# Open the folder
cd Portfolio-Website
```

Then open the project in a browser or start a local server.

## Customization

To personalize the portfolio:

- Update the name, role, bio, and contact details in `index.html`
- Modify colors, spacing, and layout in `style.css`
- Add or remove projects in the projects section
- Replace images and poster assets in the root and `posters/` directory
